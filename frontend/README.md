**# AI-Powered Todo List & Daily Diary**

An intelligent productivity management application built using the MERN Stack, FastAPI, and DistilBERT Transformer-based Deep Learning model. This application helps users manage daily tasks, maintain personal diaries, analyze their activities, and receive personalized motivational feedback to improve productivity and habits.

**## Features**

\- User registration and authentication
\- Create, update, delete, and manage daily tasks
\- Track completed and pending tasks
\- Maintain a daily diary/journal
\- AI-based analysis of daily activities
\- Productivity insights based on task completion and diary entries
\- Personalized motivational questions and feedback
\- Natural Language Processing using DistilBERT
\- Responsive and user-friendly interface

**## Tech Stack**

**### Frontend**
\- React.js
\- Vite
\- CSS / Tailwind CSS

**### Backend**
\- Node.js
\- Express.js
\- MongoDB

**### AI Service**
\- Python
\- FastAPI
\- DistilBERT Transformer Model
\- Natural Language Processing (NLP)

**## Application Workflow**

1\. Users create tasks and maintain daily diary entries.
2\. Completed tasks and diary content are collected for analysis.
3\. The FastAPI AI service processes the text data using the DistilBERT model.
4\. The system analyzes daily activities and generates productivity insights.
5\. Users receive motivational feedback and suggestions for improvement.
